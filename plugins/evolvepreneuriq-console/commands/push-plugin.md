description: "Maintainer only — push updated plugin files to the evolvepreneuriq-plugins GitHub repo"
---

Push the updated Evolvepreneur iQ Workplace plugin files to GitHub. Bump the version in `version.json`, `.claude-plugin/marketplace.json`, and `plugins/evolvepreneuriq-console/.claude-plugin/plugin.json` together, add a `CHANGELOG.md` entry, then push every changed file through the browser upload flow. Run the data-safety scan on staged files before every commit — no client names, emails, or figures may reach the public repo.

Use the `github-plugin-push` skill for this.
